# Ferreira Studio PRO

## Recursos incluídos
- Catálogo virtual responsivo
- Carrinho de compras
- Finalização via WhatsApp
- Exibição da chave Pix
- Integração com Instagram
- Edição simples no arquivo `produtos.js`

## Publicação
Recomenda-se hospedar em Netlify, Vercel ou GitHub Pages.

## Área administrativa
Os produtos são gerenciados diretamente em `produtos.js`, permitindo alteração de nome, descrição, preço e imagem sem necessidade de backend.

## Domínio personalizado
Após publicar, você pode conectar um domínio próprio.
